# OpenV Group Website - Masterplan

## 1. Vision
Build a premium enterprise technology website for OpenV Group that reflects quality, scalability, and exceptional user experience. The design language follows the approved mockup, prioritizing a high-end SaaS aesthetic comparable to industry leaders like Vercel, Stripe, and Microsoft Azure.

## 2. Technical Stack
- **Build Tool:** Vite
- **Styling:** Tailwind CSS (Modular architecture)
- **Scripting:** Vanilla JavaScript (ES Modules)
- **Animations:** GSAP (GreenSock Animation Platform)
- **Scrolling:** Lenis Smooth Scroll
- **Slider:** SwiperJS
- **Icons:** Lucide Icons

## 3. Project Architecture
The project follows a modular and scalable architecture:
- `/src/css/`: Global styles, design tokens, and component-specific CSS.
- `/src/js/modules/`: Reusable JavaScript modules (scroll, animations, navigation).
- `/src/assets/`: Static assets including optimized images and fonts.
- `/public/`: Static files served directly.

## 5. Design System Rules
- **Typography:** Manrope for headings, Inter for body.
- **Color Palette:** Navy (#07111C), Primary Green (#13C46B), Accent Blue (#1B8EFF).
- **Spacing:** 8-point grid system.
- **Animations:** Subtle, expensive, and purposeful using GSAP.
