# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-07-10
### Added
- Initial project architecture and foundation.
- Vite configuration for Vanilla JS development.
- Tailwind CSS setup with custom design tokens (Colors, Spacing, Typography).
- Global CSS architecture with reusable component styles (Buttons, Cards, Containers).
- Core JavaScript modules:
  - `scroll.js`: Lenis smooth scroll initialization.
  - `animations.js`: GSAP animation utilities (FadeIn, Stagger, Reveal).
  - `navigation.js`: Header scroll effects and mobile menu logic.
- Project documentation:
  - `README.md`: Setup and architecture overview.
  - `OPENV_GROUP_MASTERPLAN.md`: Strategic development roadmap.
  - `CHANGELOG.md`: Version tracking.
- HTML shell with navigation and footer structure.
